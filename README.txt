RZ SHOP — TEMPLATE WEBSITE TOKO AKUN GAME

CARA MEMBUKA
1. Ekstrak ZIP.
2. Buka index.html untuk melihat halaman toko.
3. Buka admin.html untuk menambah/menghapus produk.
4. Buka kedua halaman di browser yang sama agar data localStorage terbaca bersama.

FITUR YANG MENIRU VIDEO
- Halaman depan bertema RZ Shop dengan banner Selamat Datang.
- Pilihan game favorit: Semua, Free Fire, Mobile Legends, Lainnya.
- Katalog akun, pencarian, urutan harga, label promo dan detail produk.
- Form Tambah Akun Baru: judul akun, game, kategori template, harga coret, harga jual promo, diskon, badge, deskripsi, detail, upload foto.
- Daftar produk admin dan hapus produk.
- Login/daftar pelanggan, keranjang, checkout melalui WhatsApp (nomor tujuan belum ditentukan sehingga membuka WhatsApp dengan pilihan chat).
- Logo RZ menggunakan gambar logo yang kamu kirim.

PENTING
Ini template front-end demo. Data disimpan di localStorage browser, bukan database online. Akun login tidak aman untuk toko sungguhan. Untuk online multi-perangkat, perlu backend/database dan autentikasi aman. Admin.html belum memiliki pengamanan server; jangan publikasikan sebagai panel admin terbuka.
Untuk mengatur nomor WhatsApp tujuan, buka app.js dan ganti https://wa.me/?text= menjadi https://wa.me/62NOMORWA?text= (gunakan kode negara, tanpa tanda +).
Foto produk upload disimpan di browser perangkat admin; perangkat lain tidak otomatis melihatnya. Untuk toko sungguhan, gunakan storage online dan database.
