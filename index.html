NEED TO KNOW

Pertanyaan umum.

Apakah produk di katalog sudah tersedia? ＋

Belum tentu. Produk yang tampil saat ini adalah data contoh untuk demo. Ganti dengan produk dan stok milik toko sebelum website dipublikasikan.

Bagaimana cara mengganti produk? ＋

Buka file script.js, lalu ubah daftar pada bagian products. Petunjuk lebih lengkap tersedia di README.

Apakah pembayaran sudah aktif? ＋

Belum. Template ini hanya menyediakan antarmuka katalog. Integrasi pembayaran, database, dan panel admin perlu ditambahkan secara terpisah.

Bagaimana cara memasang logo dan karakter? ＋

Logo dan karakter dari file yang kamu kirim sudah dipasang di folder assets.
